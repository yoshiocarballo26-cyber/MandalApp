# MandalApp

Generador de mandalas tipo espirógrafo, 100% en el navegador — sin instalación, sin cuenta, sin servidor. Un solo archivo HTML.

## ¿Qué hace?

- Brazos encadenados (o, en **modo Gravedad**, planetas orbitando un agujero negro central con física real) que dibujan mandalas geométricos en tiempo real.
- Control individual por brazo: radio, velocidad, dirección, color y estela.
- Simetría radial, entrelazado, presets listos para usar.
- Vista de disco 3D, rotación automática del eje, auto-pausa por vueltas.
- Galería local (guardada en tu navegador) y exportación a PNG.

## Cómo usarlo

Abre `mandalapp.html` directamente en cualquier navegador moderno — no necesita instalación ni conexión a internet una vez cargado.

También está publicado en vivo vía GitHub Pages: `https://TU-USUARIO.github.io/TU-REPO/mandalapp.html` (actualiza este link cuando actives Pages).
